Esta é a caixa de ferramentas principal do desenvolvedor Progress. Ela dá acesso rápido aos utilitários do ambiente.

# Ambiente, Sessão e Arquivos
Esses atalhos ajudam você a entender e configurar o terreno onde seu código está rodando.

Confg info: Exibe todas as configurações de inicialização da sua sessão do Progress, incluindo parâmetros de startup, variáveis de ambiente e caminhos lidos do arquivo .ini ou registro do Windows.

DB List: Lista rapidamente todos os bancos de dados lógicos e físicos que estão conectados na sua sessão atual.

Os prompt: Abre uma janela de terminal/prompt de comando nativo do sistema operacional sem precisar sair do ambiente Progress.

Propath: Abre o editor do Propath. O propath é a lista de diretórios que o Progress vasculha em busca de arquivos .p, .w ou .r para compilar ou executar. Essencial para organizar pastas de projetos.

Run: Abre uma caixa de diálogo simples para executar qualquer programa diretamente pelo seu caminho, sem precisar abrir o código. 

# Desenvolvimento de interface e Ferramentas Visuais (UI)

Focados em manipular os elementos visuais (widgets) que os usuários veem.

Color changer: Permite modificar as paletas e tabelas de cores padrão configuradas para o ambiente gráfico.

Set font 2: Utilitário para gerenciar a tabela de fontes (fontes mapeadas de 0 a 255 no Progress) e testar como elas ficarão na tela.

Control hierarchy: Mostra a árvore de dependência (hierarquia "pai-filho") dos objetos visuais que estão em memória (ex: qual Frame contém qual Fill-in).

Window viewer: Lista as janelas (Windows) atualmente instanciadas e em execução na sua sessão.

Windows info: Permite inspecionar os handles (ponteiros de memória) e atributos técnicos  detalhados de janelas abertas.
